## Study and answer protection

The shared illustration viewer supplies the footer to module galleries, expanded lessons, glossary images and practice feedback. Learn shows eligible links. Active Recall hides them until its labels are fully revealed. Practice is fail-closed until the existing answer-revealed/submitted state, even if individual marker labels are manually toggled. Unknown and partial mappings render no link. No grading/scoring implementation is changed.

Native uses the OS HTTPS URL opener; web retains a real accessible link and opens a separate tab. Neither uses app navigation, resets the viewer, writes progress nor replaces the current lesson. The footer is outside the diagram gesture surface, has a minimum 44-point touch target and uses existing themed/scaled text. Only a failed open shows a short localized message inviting another tap. There is no new always-visible banner. Source pages need internet; bundled diagrams and existing offline behavior are unchanged.
