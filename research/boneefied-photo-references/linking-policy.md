# Source-page linking policy

Checked 2026-11-06. These are research criteria, not a legal opinion or a grant
of reproduction rights. No external image is added to Boneefied.

## Reference acceptance

- The target is a public educational **source page** with the image and context,
  not a raw image, search result, embedded frame or home page.
- The image must actually have been seen on that destination, and the caption
  and source metadata checked. Search snippets, filenames, previous asset
  verification and a successful HTTP response are insufficient.
- Record the actual named photographer/creator and institution when established.
  If identity or organism remains unconfirmed, say so rather than filling it in.
- Distinguish human specimen photographs, microscopy, and diagnostic imaging.
  Unknown/nonhuman material must not be presented as a human counterpart.
- Use a small, specifically named set for composite plates only when those
  references actually cover their different subjects. Partial coverage is not
  complete coverage.
- Abstract schematics may have relevant real examples, not literal photographic
  equivalents. Explain that relationship explicitly.
- Any source-specific linking restriction takes precedence over general
  guidance. An attribution or an openly accessible page is not by itself
  permission to copy.
- Reproduction-license metadata is recorded separately; no copying permission
  is exercised by this command.

## Evidence and implementation boundary

Only source metadata, short original research descriptions, exact source-page
URLs, and verification outcomes belong in the records. No source photograph,
thumbnail, article quotation, image embedding, download, application UI, question,
numbering, progress or source-provenance change is part of this command.

The later link-only command must use eligible records only and guard Recall/
unanswered graded contexts against answer leakage. Unresolved or partially
reviewed candidates must not acquire a clickable fallback search link.
