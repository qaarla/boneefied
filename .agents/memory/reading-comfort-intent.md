---
name: Reading comfort scope
description: Boundaries for Boneefied foreground-only reading-comfort calibration.
---

Reading-comfort calibration is limited to eligible ordinary reading text in
existing light appearances across this project's existing surfaces. Leave
comfortably toned text alone. The user's charcoal example is not permission
for a blanket replacement.

Existing dark/night colors and behavior must remain untouched, including text.
Preserve backgrounds, Tinos and all typography metrics, controls, navigation,
links, brand/semantic colors, diagrams, imagery and behavior. Do not add
settings, opacity, filters, builds or publishing.

**Why:** The user explicitly requested only subtle text-foreground comfort
adjustments, not a theme change, and emphasized that night/dark mode must not
be tampered with.

**How to apply:** Inspect actual backgrounds, including material pixels, and
prefer at least 7:1 normal-reading contrast with a hard 4.5:1 floor. Use an
opt-in reading color rather than replacing a shared foreground used by
controls, icons, headings or diagram labels. Report unchanged surfaces and
distinguish source/preview work from installed or published updates.
