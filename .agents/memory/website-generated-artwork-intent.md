For the Boneefied website, the user explicitly superseded the earlier SVG,
traced-line and border-decoration approach. Use image-generated artwork with a
dark palette and existing anatomy-appropriate accents. The entire scrolling UI,
including central backgrounds and opaque interface surfaces, must visibly carry
rich-but-muted organic anatomical material. Preserve Tinos, layout, functionality
and protected scientific imagery.

**Why:** The user repeatedly rejected minimal edge ornament and technique-led
substitutions for the requested finished surface.

**How to apply:** Do not substitute SVG paths, hand-coded strokes, clip art or
CSS-generated art. If generation is unavailable, say so. Check actual desktop
and mobile website views and distinguish preview evidence from deployed
evidence. Do not claim a new asset is public before checking the public site.
This correction is website-only; it does not authorize native-app changes,
other projects, task-board items, recreated archived suggestions or publishing.
