---
name: Study module icon intent
description: The user's visual direction for Boneefied Study module illustrations.
---

Study module icons should be simple, legible, understated matte anatomy illustrations—not busy, cartoonish, or glossy. Keep them visually consistent with Boneefied and with the icon style used in the user's other apps.

**Why:** The user specified this direction when requesting that module-number badges be replaced.

**How to apply:** Preserve this direction in future Study module icon refinements; do not treat the badge change as permission to redesign the screen.
