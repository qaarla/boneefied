name: Study system explorer intent
description: The user's required bounded scrolling behavior for Explore by system.
---

Explore by system must remain one compact, rounded internal vertical scroller, including with enlarged text and long translated labels. Do not replace it with a full-page stack for accessibility reflow. Internal gestures scroll rows; gestures outside scroll the page. Preserve room below for Learning modules and existing bottom-dock clearance.

**Why:** The user explicitly identified the tall full-page stack as a regression and requested restoration of the intended scroller, without redesigning Learning modules or other screens.

**How to apply:** Reflow text within natural-height rows, not by unbounding the system list. Keep first and last rows reachable at all text sizes and preserve selection/filtering behavior.
