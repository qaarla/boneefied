# Boneefied foundational atlas: visual standard

Original 2D vector plates, generated by `scripts/atlas/generate.mjs` from shared tokens (`tokens.mjs`) and shapes (`base.mjs`). Run `node scripts/atlas/generate.mjs` to regenerate the SVG masters, PNG siblings, `provenance.json` and `content/atlas-plates.generated.ts`.

- Style: flat, matte, low-saturation medical illustration. No gradients, textures, filters, glows, photos or baked text.
- Canvas 1450 x 1000 (aspect 1.45), contained by the existing AnatomyImageViewer with generous margins.
- Atlas UI labels use measured, disjoint numbered callouts and leader lines to unchanged anatomical coordinates. Keep controls below the illustration, minimum 44-pixel label targets, and a separate scalable legend. Extra canvas height may be needed for enlarged text; the base illustration retains its original contain ratio.
- Strokes: outline 2.2, detail 1.1, fine 0.8 (local units). Overlapping parts use an outline pass under a flat fill pass.
- Palette: warm paper ground, skin, slate ink, bone, and muted organ tints (see tokens.mjs). Axial bones blue-gray, appendicular bones sand.
- Orientation: anterior view patient right = viewer left; posterior view patient right = viewer right. Palms forward, thumbs lateral.
- Names live in label metadata and localized captions, never in the image.
- Rights: original Boneefied project artwork, all rights reserved, no CC0. Text-only factual references (NCI SEER, MedlinePlus) are listed in provenance.json; no outside image was imported or traced.
